Desktop widget concept

Spotify Deck

Designing a KDE Plasma desktop media widget with a local-first security boundary.

KDE Plasma 6QMLDBusMPRISSecurity design

The idea

I wanted a small Spotify controller on my KDE desktop without dealing with API keys or account logins. Spotify Deck is the design I wrote up for that. The public repository has documentation, but I haven't published a working applet.

How it would work

The widget would read track information and send playback commands through KDE's MPRIS integration over DBus. QML would handle the interface. That keeps controls on the local desktop instead of using Spotify's Web API.

Security considerations

The design doesn't require OAuth tokens or stored Spotify credentials. I also documented avoiding shell commands built from track metadata. Those are design choices, not claims about a tested application.

Still to do

Write the QML applet, test it on KDE Plasma 6, and add screenshots and installation steps once it works.
