Recipe Recommender

A Python/Flask web app that connects user-facing recipe recommendations with reproducible Linux automation and CI checks.

PythonFlaskpytestBashGitHub Actions

Overview

This collaborative DevOps course project lets users enter ingredients, meal type, and dietary preferences to find matching recipes. The repository includes a Flask interface and recommendation logic, plus scripts and an automated workflow for testing and packaging the application.

Architecture & approach

Flask receives requests and renders templates. Recommendation logic lives in separate Python modules. Local scripts install dependencies, run tests, exercise a /health endpoint, and build a .tar.gz deployment artifact. A GitHub Actions workflow repeats those checks on repository events.

Engineering takeaways

  • Separated application logic from Flask request handlers.
  • Used unit and integration tests, plus a live-process smoke check.
  • Packaged a Linux deployment artifact through a GitHub Actions workflow.
  • Worked with a teammate on a reproducible development workflow.

Security perspective

The /health endpoint is intended for a smoke test. A potential next iteration would add stricter input validation, dependency scanning, and hardening of deployment settings; these are improvement ideas, not claims about existing protections.
