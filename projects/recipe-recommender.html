Recipe Recommender

A Python/Flask web app that connects user-facing recipe recommendations with reproducible Linux automation and CI checks.

PythonFlaskpytestBashGitHub Actions

The project

My teammate and I built a Flask app that suggests recipes based on ingredients, meal type, and dietary preferences. It was our Linux DevOps course project, so a big part of the work was getting the testing and build process in place.

How it works

Flask handles the form and results pages. The recipe matching logic lives in a separate Python module, with local recipe data. There is also a /health endpoint for checking that the app starts.

Testing and automation

We used pytest for unit and integration tests. Bash scripts handle setup, tests, a running-app smoke test, and packaging. GitHub Actions runs those steps on pushes and pull requests and uploads a .tar.gz build artifact.

What I'd improve

I'd add dependency scanning and stricter input validation, then test an actual deployment instead of stopping at a packaged build.
